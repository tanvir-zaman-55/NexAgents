Deploy the current Chef project to production.

Guide the user through:
1. Ensure all changes are committed with git
2. Push to Convex production deployment using `npx convex deploy`
3. Deploy the frontend to Vercel or their hosting platform
4. Provide the production URLs when complete

Important: Verify that:
- Tests are passing (if any exist)
- Environment variables are set for production
- The Convex schema is up to date

Ask the user to confirm before deploying to production.
